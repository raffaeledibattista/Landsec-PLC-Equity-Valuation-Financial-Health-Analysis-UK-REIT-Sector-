# Landsec-PLC-Equity-Valuation-Financial-Health-Analysis-UK-REIT-Sector-
Equity valuation &amp; credit analysis of Land Securities Group PLC (£10.9bn UK REIT). Modeled a 5-year forecast combining a Two-Stage Dividend Discount Model (DDM) and EPRA peer multiples (18% upside). Analyzed capital structure, debt covenants, and central London office/retail portfolio recycling.
